Vice Cover Studio turns a photo and a caption into GTA-style multi-panel cover art — a Vice City sunset or neon grade, palm silhouettes, halftone and grain, bold Anton lettering — and exports it as a PNG in square, portrait or wide post sizes. Four layouts, five colour grades, drag-to-frame panels, all offline in the browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Add a photo, pick a layout and a grade, write the caption, then Export PNG.
